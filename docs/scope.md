# Scope

## In scope

<!-- What the product will do by November 19. Two to five items. -->

- Collect events from the places they are announced today (email, flyers, Instagram) into one list
- Show a commuter this week's events, soonest first, each one listed once
- A simple page a student can open on their phone between classes

## Out of scope

<!-- What you decided NOT to build this semester, and one line on why. -->

- Accounts and logins: a student should not have to sign up to see what is on this week
- Reading Instagram automatically: the API needs approval we cannot get in nine weeks, so events arrive as a file
- Reminders and notifications: useful, but only once people are using the list
